Tu modelo Qwen3.8 está disponible como API

Usa la URL de esta Application para enviar mensajes a qwen3.8-27b-fp8. La ruta principal es /v1/chat/completions; con stream: true la respuesta llega por partes.

URL base de esta Application {{BASE_URL}} Para clientes OpenAI añade /v1. La URL pública puede requerir autenticación propia de Cloudera.

Primera llamada

Comprueba /health y /v1/models; después prueba una conversación breve.

Terminal · streaming SSE

curl

La opción -N muestra cada fragmento al llegar.

curl -N '{{BASE_URL}}/v1/chat/completions' \
  -H 'Content-Type: application/json' \
  -d '{"model":"qwen3.8-27b-fp8","messages":[{"role":"user","content":"Hola, responde en una frase."}],"max_tokens":128,"stream":true}'
Python · cliente OpenAI

SDK

El SDK necesita un valor en api_key aunque vLLM no exija clave.

import os
from openai import OpenAI

client = OpenAI(
    base_url="{{BASE_URL}}/v1",
    api_key=os.getenv("QWEN_API_KEY", "EMPTY"),
)

for chunk in client.chat.completions.create(
    model="qwen3.8-27b-fp8",
    messages=[{"role": "user", "content": "Hola"}],
    max_tokens=128,
    stream=True,
):
    text = chunk.choices[0].delta.content
    if text:
        print(text, end="", flush=True)

Autenticación: si configuraste QWEN_API_KEY, envía Authorization: Bearer TU_CLAVE en curl o usa esa clave en el SDK. El acceso público de Cloudera puede requerir otra autenticación y puede usar el mismo encabezado; compruébalo en tu instalación antes de llamar desde fuera.

Rutas útiles

Estas rutas están disponibles en el servidor mostrado en los logs.

POST /v1/chat/completions

Conversación, texto o una imagen por petición; admite streaming.

GET /v1/models

Modelo servido y nombre exacto para el campo model.

GET /health

Comprobación rápida de disponibilidad del servidor.

GET /docs

Esquema interactivo de todas las rutas y campos del servidor.

Parámetros de la petición

Los más útiles en /v1/chat/completions. En el SDK de OpenAI, pasa los campos propios de vLLM mediante extra_body; en HTTP van directamente en el JSON.

CampoUsoNotas
modelNombre del modeloqwen3.8-27b-fp8; requerido en los ejemplos.
messagesHistorial con roles system, user y assistantIncluye la pregunta actual.
max_tokensLímite de tokens de salidaTambién se admite max_completion_tokens. El total de entrada y salida debe caber en el contexto.
streamtrue para recibir fragmentos SSEUsa un cliente que no acumule toda la respuesta.
temperatureVariación en la generaciónEl modelo carga por defecto 1.0 desde su configuración.
top_pMuestreo por probabilidad acumuladaEl modelo carga por defecto 0.95.
top_kLimita los candidatos por pasoPropio de vLLM; el modelo carga por defecto 20.
min_pUmbral relativo para candidatosPropio de vLLM; usar mediante extra_body.
repetition_penaltyReduce o aumenta repeticionesPropio de vLLM; 1.0 es neutro.
presence_penaltyFavorece temas nuevosParámetro compatible con Chat Completions.
frequency_penaltyPenaliza términos frecuentesParámetro compatible con Chat Completions.
stopTexto que detiene la salidaCadena o lista de cadenas.
seedSemilla de muestreoPuede ayudar a reproducir una petición.
response_formatFormato restringido, por ejemplo JSONConsulta el esquema de /docs para sus variantes.

En esta Application el contexto máximo está configurado a 262 144 tokens y se admite una imagen por petición; el vídeo está deshabilitado. Las herramientas automáticas y el parser de razonamiento requieren configuración adicional del servidor.

Ejemplo de parámetro propio de vLLM en Python: extra_body={"top_k": 20, "min_p": 0.05}. Para la lista completa y los tipos exactos consulta OpenAPI de esta instancia y la documentación de vLLM 0.29.0.
